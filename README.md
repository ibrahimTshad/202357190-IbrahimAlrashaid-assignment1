# Ibrahim Alrashaid — Personal Portfolio

## Project Description

This project is a responsive personal portfolio website created for Assignment 1: Foundation & AI Integration. It introduces me, presents two academic projects, and provides a contact form. The website was built to practice foundational HTML, CSS, and JavaScript skills while learning how to use AI tools responsibly during development.

## Features

- About Me section with a short personal introduction
- Projects section featuring a five-stage pipelined CPU and an assignment tracker
- Contact form with name, email, and message fields
- Dark and light theme toggle
- Responsive project layout for desktop, tablet, and mobile screens
- Accessible labels, alternative image text, and semantic HTML elements

## Technologies Used

- HTML5 for the page structure and content
- CSS3, Grid, and Flexbox for styling and responsive layout
- JavaScript for the theme toggle and page interactions
- Git and GitHub for version control and project hosting
- ChatGPT for development assistance, troubleshooting, and documentation support

## Running the Website Locally

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation, package manager, or backend server is required.
